# 推石头的人 — The Stone Pusher

一本由匿名工程师写下的哲学随笔：熵增、西西弗斯，以及「在注定失败的前提下，人为什么还要做」。

Philosophical essays by an anonymous engineer: entropy, Sisyphus, and why we keep pushing the stone.

## 如何阅读

按文件名顺序浏览 `chapters/` 目录下的 Markdown 文件即可。

推荐 VS Code + Markdown Preview Enhanced 插件，或者 Typora。

## 这本书讲了什么

这不是一本技术书，也不是教程。它不依赖任何技术知识，只问一个问题：**在注定失败的前提下，人为什么还要做？**

全书在三条线上编织，层层递进：

- **物理线**（宇宙视角）：熵增、兰道尔定理、邓煜与希尔伯特第六问题——「世界默认是混乱的」。
- **人文线**（人类视角）：西西弗斯、陀思妥耶夫斯基、刘慈欣——「人在混乱中选择创造意义」。
- **工程师线**（匿名视角）：一个写代码的人，在夜里面临选择——「一个具体的人如何回应这两个视角」。

结构：

- 楔子：一个写代码的人，为什么要想这些问题？
- 第一章 熵增：宇宙的默认状态（3 节）
- 第二章 人类：局部的抗熵增运动（3 节）
- 第三章 技术：我们对抗混乱的工具（2 节）
- 第四章 西西弗斯（4 节）
- 第五章 自指悖论（3 节）
- 第六章 AI 与未来（3 节）
- 第七章 致自己（3 节）
- 尾声：石头还在推
